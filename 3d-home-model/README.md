# 32 Ruskin Street, Elwood — 3D Model

A stylised Three.js massing model of the house, built from the real floor
plan (room dimensions) and street/interior photos: heritage brick facade
with verandah and gable roof, the four-bedroom hallway wing, a lightcourt,
the kitchen/dining/living glass pavilion, the timber-batten alfresco pergola,
and the rear pool/spa off the laneway.

This lives in an unrelated repo (`weeklyplanner`) only because that's where
this session had write access — it isn't part of the work tracker app.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL. Drag to orbit, scroll to zoom, and use the
view buttons (street / aerial / pool / living pavilion) to jump around.

## Build

```bash
npm run build
npm run preview
```
